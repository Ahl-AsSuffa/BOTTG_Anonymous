# Анонимный чат бот для мессенджера Телеграмм

Telegram-бот для поиска случайного собеседника и общения в анонимном чате.
Пользователь проходит небольшую начальную настройку, после чего может найти другого участника и начать переписку. Бот поддерживает поиск собеседника, завершение диалога, ограничение количества сообщений и простую систему администраторов. 
Возможности: 
 - Регистрация пользователя при первом запуске.
 - Выбор пола во время начальной настройки.
 - Поиск случайного собеседника.
 - Анонимная передача текстовых сообщений.
 - Завершение текущего диалога.
 - Уведомление собеседника о выходе из чата.
 - Ограничение количества доступных сообщений.
 - Просмотр оставшегося лимита сообщений.
 - Загрузка и сохранение пользователей в JSON-файл.
 - Загрузка и сохранение списка администраторов.
 - Отдельная клавиатура для администраторов.
 - Игнорирование сообщений из групповых чатов.
 - Пропуск старых Telegram-обновлений после запуска бота. 
Технологии: 
 - C#
 - .NET
 - Telegram Bot API
 - Telegram.Bot
 - System.Text.Json
 - JSON для хранения данных
